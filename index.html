How to Get Your Meetup.com Cookie

📋 Quick Steps

  1. Open meetup.com and log in
  2. Open your browser's Developer Tools (F12 or Cmd+Option+I on Mac)
  3. Go to the Network tab
  4. Refresh the page (F5 or Cmd+R)
  5. Click on any request to meetup.com
  6. Find the Request Headers section
  7. Copy the entire Cookie header value
  8. Paste it into the cookie field in this app

🌐 Browser-Specific Instructions

Google Chrome / Edge / Brave

  1. Press F12 or Cmd+Option+I (Mac) to open DevTools
  2. Click the Network tab
  3. Refresh the page with F5 or Cmd+R
  4. Click on the first request (usually the page URL)
  5. In the right panel, scroll down to Request Headers
  6. Find the cookie: line
  7. Right-click the cookie value and select Copy value

Firefox

  1. Press F12 or Cmd+Option+I (Mac) to open Developer Tools
  2. Click the Network tab
  3. Refresh the page with F5 or Cmd+R
  4. Click on any request to meetup.com
  5. Click the Headers tab in the right panel
  6. Scroll to Request Headers
  7. Find Cookie and copy its entire value

Safari

  1. Enable Developer menu: Safari → Preferences → Advanced → Show Develop menu
  2. Press Cmd+Option+I to open Web Inspector
  3. Click the Network tab
  4. Refresh the page with Cmd+R
  5. Click on a request to meetup.com
  6. In the right panel, find Request Headers
  7. Copy the Cookie header value

⚠️ Important Notes

  • Security: Your cookie is stored locally in your browser and never sent to any third-party servers (only to Meetup.com via our local proxy)
  • Privacy: Cookies contain authentication tokens - treat them like passwords
  • Expiration: Cookies may expire after some time. If you get authentication errors, get a fresh cookie
  • Format: The cookie should be a long string with multiple key=value pairs separated by semicolons

💡 Example Cookie Format

MEETUP_MEMBER=id=123456789&status=1; MEETUP_TRACK=id=abc123; _ga=GA1.2.123456789.1234567890; ...

Your actual cookie will be much longer and contain many more values.
